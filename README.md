## 作品概要
- **開発環境**：C# / Unity
- **開発期間・人数**：2025年8月～2025年9月（2ヶ月） / 個人制作

## 特徴
- 探索、謎解き、戦闘要素を取り入れたトップダウン型アクションゲーム
- PolygonCollider2Dの頂点情報から「耳切り法」で動的に可視化する攻撃予告メッシュ
- FSM（有限状態マシン）とHP条件に基づく多段階（フェーズ変化）ボスAI

## 技術的工夫
### 1. 耳切り法（Ear Clipping）アルゴリズムを用いた攻撃判定メッシュの動的生成
PolygonCollider2Dの複雑な形状から、コード上で三角形インデックスを算出する自作アルゴリズムを実装しました。<br>
判定と一致する攻撃予告メッシュをリアルタイムで生成し、スプライト反転に合わせた頂点座標の再計算や、生成ごとの旧メッシュ破棄によるメモリリーク対策、シェーダーの描画モードの動的制御まで処理しています。

### 2. FSM（有限状態マシン）とHP条件に連動したフェーズ移行型AI
EnumとSwitch文を用いたFSMを構築し、UpdateとFixedUpdateの実行責務を分離しました。<br>
また、ボスの残りHPが50％未満になったタイミングで即座に第2フェーズへと移行させ、移動速度や攻撃パターンの切り替えを破綻なく制御しています。

## 課題と解決策
- **課題：** PolygonCollider2Dから耳切り法を用いて攻撃予告の2Dメッシュを生成した際に、メッシュが正しく描画されない現象が発生。
- **原因と解決：** 三角形インデックスを構築する際、頂点の回り順（時計回り/反時計回り）が考慮されておらず、法線ベクトルが反転してカメラに対して裏面と判定されていたことが原因でした。<br>
頂点列の符号付き面積から回り順を判定し、自動で時計回りにソートする関数を実装。さらに、三角形の外積を用いた凸判定ロジックを見直し、メッシュ生成後に法線ベクトルと境界ボックスの再計算を徹底することで、正しく描画されるよう修正しました。
